วิธีใช้งาน
    1. ให้สิทธิโฟร์เดอร์
        - chmod -R 777 ชื่อโปรเจค

    2. แตก zip ไฟล์ node_modules.tar.gz และ vendor.tar.gz
        - tar xfz node_modules.tar.gz
        - tar xfz vendor.tar.gz

    3. สร้าง key
        - php artisan key:generate
        - php artisan storage:link

    4. ตรวจดูการสร้างตาราง user
        - database > migrations > 2014_10_12_000000_create_users_table.php
        - สร้าง migrations ใช้คำสั่ง php artisan migrate
        - ถ้าลบ migrations ใช้คำสั่ง php artisan migrate:rollback

    5. ตรวจสอบ Module user
        - app > Http > Module > User.php

    6. เลือกวิธีตรวจสอบ/ให้สิทธิ์/เช็คสิทธิ กลุ่มผู้ใช้งาน
        - app > Http > Controllers > Auth > LoginController.php

    7. ตรวจเช็คเงื่อนไขใน HomeController.php
        - app > Http > Controllers > HomeController.php
