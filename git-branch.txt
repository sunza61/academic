------------------------------
จัดให้ครับ! นี่คือคัมภีร์สรุปขั้นตอน "ดู-เลือก-ทำ-รวม-ลบ" แบบ Step-by-Step สำหรับใช้ใน Terminal ของคุณครับ
------------------------------
## 1. ดู (View Branches)
ตรวจสอบดูว่าตอนนี้เรามีกิ่งไหนบ้าง และตัวเราอยู่ที่กิ่งไหน

* คำสั่ง: git branch (ดูในเครื่อง) หรือ git branch -a (ดูทั้งหมดรวม Server)
* สังเกต: กิ่งที่มีเครื่องหมาย * นำหน้า คือกิ่งที่คุณกำลังทำงานอยู่

## 2. เลือก / สร้าง (Checkout & Create)
สลับไปกิ่งที่มีอยู่แล้ว หรือสร้างกิ่งใหม่เพื่อเริ่มงาน

* สลับไปกิ่งที่มีอยู่: git checkout feature/login-new
* สร้างใหม่และสลับทันที: git checkout -b feature/my-test
* การทำงาน: Git จะเปลี่ยนไฟล์ในเครื่องคุณให้เป็นเวอร์ชันของกิ่งนั้นๆ

## 3. ทำ (Work & Commit)
แก้ไขโค้ด ทดสอบจนพอใจ แล้วทำการบันทึก

* เตรียมไฟล์: git add . (เลือกไฟล์ทั้งหมดที่แก้)
* บันทึก: git commit -m "อธิบายสั้นๆว่าแก้ตัวไหนไป"
* การทำงาน: เป็นการตอกหมุดไว้ว่ากิ่งนี้ทำอะไรเสร็จไปแล้ว

## 4. รวม (Merge)
เอางานจากกิ่งแยก กลับมาใส่ในกิ่งหลัก (main)

   1. ต้องสลับกลับไปที่ตัวรับก่อน: git checkout main
   2. สั่งรวมร่าง: git merge feature/login-new


* การทำงาน: โค้ดที่แก้ในกิ่งแยกจะไหลเข้ามาอยู่ใน main ทันที

## 5. ลบ (Delete)
เมื่อรวมงานเสร็จแล้ว ก็ลบกิ่งที่ไม่ได้ใช้ทิ้ง

* คำสั่ง: git branch -d feature/login-new
* การทำงาน: ลบชื่อกิ่งออกจากรายการ เพื่อให้โปรเจกต์สะอาด ไม่งงว่ากิ่งไหนทำค้างไว้

------------------------------
ลำดับคำสั่งที่กดรัวๆ ได้เลย:

git branch                     # 1. ดู
git checkout feature/login-new # 2. เลือก# ... แก้โค้ดในไฟล์เสร็จแล้ว ...
git add .                      # 3. ทำ (เตรียม)
git commit -m "fixed login"    # 3. ทำ (บันทึก)
git checkout main              # 4. รวม (กลับที่หลัก)
git merge feature/login-new    # 4. รวม (ดึงงานมา)
git branch -d feature/login-new # 5. ลบ (ทำความสะอาด)

ตอนนี้คุณอยู่ที่กิ่ง feature/login-new และ working tree clean แล้ว พร้อมที่จะเริ่มขั้นตอนที่ 3 (แก้ไขไฟล์) หรือยังครับ? หากแก้เสร็จแล้วบอกผมนะ เดี๋ยวช่วยดูวิธีรวมร่างครับ!

------------------------------------------------------------------------------------------------
ได้แน่นอนครับ! กรณีนี้คือการ "ยกเลิกสิ่งที่ Merge พลาดไป" แล้วกลับไปเอาสิ่งใหม่ที่ถูกต้องมาใส่แทน โดยมี 2 ขั้นตอนหลักคือ Undo (ถอยหลัง) และ Merge (รวมใหม่) ครับ
ทำตามลำดับนี้ได้เลย:
## 1. ถอยหลัง (Undo) กิ่ง main กลับไปก่อนที่จะ Merge พลาด
เนื่องจากคุณเผลอ Merge feature/login-new 2 เข้ามา แล้วมันพัง คุณต้องทำให้ main ย้อนเวลากลับไปจุดเดิมก่อน:

git checkout main
git reset --hard HEAD~1


* คำอธิบาย: HEAD~1 คือการสั่งให้ถอยหลังกลับไป 1 ก้าว (จุดก่อนที่จะเกิดการ Merge)
* คำเตือน: --hard จะลบโค้ดที่เพิ่ง Merge พลาดเข้ามาทิ้งไปเลย เพื่อให้ main กลับมาสะอาดเหมือนเดิม

------------------------------
## 2. สลับไปกิ่งที่ถูกต้อง (feature/login-new)
ตอนนี้ main กลับมาปกติแล้ว ให้คุณไปที่กิ่งที่คุณต้องการงานจริงๆ:

git checkout feature/login-new

(ถ้าในกิ่งนี้ยังมีงานที่ต้องแก้เพิ่ม ก็แก้ให้เสร็จแล้ว git add . และ git commit ให้เรียบร้อยก่อนครับ)
------------------------------
## 3. รวมร่างใหม่อีกครั้ง (Re-Merge)
คราวนี้เราจะเอาเฉพาะกิ่งที่ถูกต้องมาใส่ใน main:

   1. สลับกลับไป main:
   
   git checkout main
   
   2. สั่งรวมจากกิ่งที่ถูก:
   
   git merge feature/login-new
   
   
------------------------------
## สรุปสถานการณ์ตอนนี้:

* กิ่ง main จะได้งานที่ถูกต้องจาก feature/login-new
* กิ่ง feature/login-new 2 (ที่พลาด) จะยังคงอยู่เหมือนเดิมแต่ไม่ได้ถูกรวมเข้ามาใน main แล้ว

คำแนะนำเพิ่มเติม:
หากคุณกังวลว่า HEAD~1 จะถอยไปผิดจุด สามารถพิมพ์ git log --oneline เพื่อดูประวัติก่อนได้ครับ ถ้าเห็นเลขรหัส Commit (เช่น abc1234) ก่อนหน้าที่จะ Merge พลาด คุณสามารถใช้ git reset --hard abc1234 แทนได้เพื่อความแม่นยำ
ตอนนี้คุณ Reset กลับมาได้สำเร็จหรือยังครับ? ให้ผมช่วยเช็ก git log ให้ไหม?
